✍ Challenge: Introduce Yourself

🎯 Objective: Learn to use the print() function.
In this challenge, you will write a short program to introduce yourself using Python. It is super easy and fun! The print() function is used to display text to the screen.
🔽 Let's Get Started! Follow these simple steps. 🚀
📌 Step 1. Do you see the black window below? That's your Python playground! 🎮 This is where you'll write your code.
📌 Step 2. Type this code to print your name (replace John with your own name!):
print("John")
📚 Example: If my name was Alice, I would write:
print("Alice")
📌 Step 3. Click Run and see your name appear on the screen! 🎉
