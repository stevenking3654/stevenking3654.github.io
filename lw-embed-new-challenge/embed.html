Problem Description

Welcome, young coder! 🚀

Your mission is to write a program that converts USD (United States Dollar) to EUR (Euro) using a fixed rate.

📏 Conversion rate: `1 USD = 0.85 EUR`

This time, we will round the result to 2 decimal places, just like real-world banking applications.

The faster you solve it, the more points you earn. Clean code = happy code! ✨

🏆 Quest

Write a Python program that:
- Asks for an amount in USD
- Converts it to EUR using a fixed rate
- Rounds the result to 2 decimal places
- Prints the final value with a `€` symbol

Example Input/Output

InputExpected Output
100Converted: €85.0
23.5Converted: €19.98
57.25Converted: €43.99

Steps to Success

  • Understand what the converter needs to do 🤔.
  • 💬 Ask the user how many USD they want to convert.
  • 📝 Use the formula: eur = usd * 0.85.
  • 📝 Use round(eur, 2) to round it.
  • 🖨️ Print something like: "Converted: €72.25".
